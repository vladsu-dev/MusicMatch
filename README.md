# 🎵 MusicMatch - Дейтинг-приложение на основе музыкальных предпочтений

## 📝 Описание проекта

MusicMatch - это инновационное дейтинг-приложение, которое помогает людям находить друг друга на основе музыкальных вкусов. В отличие от традиционных дейтинг-приложений, где пользователи оценивают только внешность, MusicMatch анализирует музыкальные предпочтения и психологическую совместимость через музыкальный профиль.

## 🎯 Основная идея

Музыка - это отражение нашей личности, эмоций и ценностей. Наш подход основан на предположении, что люди со схожими музыкальными вкусами имеют больше шансов построить гармоничные отношения. MusicMatch использует передовые технологии искусственного интеллекта для глубокого анализа музыкальных предпочтений и создания точных матчей.

## ✨ Ключевые особенности

### 1. 🤖 AI-анализ музыкальной личности
- Использование DeepSeek AI для анализа музыкального профиля
- Создание психологического портрета на основе музыкальных предпочтений
- Определение эмоционального профиля и темперамента

### 2. 💕 Умный алгоритм матчинга
- Расчет совместимости на основе музыкальных предпочтений
- Учет психологической совместимости через AI-анализ
- Процентное отображение совместимости для каждого потенциального матча

### 3. 💬 Встроенный мессенджер
- Чат в реальном времени для совпавших пар
- Обмен музыкальными рекомендациями прямо в чате
- Возможность создавать общие плейлисты

### 4. 🔄 Система свайпов
- Интуитивный интерфейс в стиле Tinder
- Отображение музыкальной совместимости на карточках
- Мгновенное уведомление о взаимных симпатиях

## 📱 API Endpoints

### Аутентификация
- `POST /api/register` - регистрация нового пользователя
- `POST /api/login` - вход в систему
- `POST /api/logout` - выход из системы

### Матчинг
- `GET /api/potential-matches` - получение потенциальных матчей
- `POST /api/swipe` - свайп (лайк/дизлайк)
- `GET /api/matches` - список совпадений

### Мессенджер
- `GET /api/messages/:match_id` - получение сообщений
- `POST /api/messages` - отправка сообщения
- `WebSocket /chat` - real-time чат

## 🗄 Структура базы данных

### Основные таблицы
- **users** - пользователи приложения
- **music_profiles** - музыкальные профили
- **swipes** - действия пользователей (лайки/дизлайки)
- **matches** - совпадения между пользователями
- **messages** - сообщения в чатах

### Связи
- Один пользователь имеет один музыкальный профиль
- Пользователь может иметь множество свайпов
- Матч создается при взаимном лайке
- Матч содержит множество сообщений

## 📊 Алгоритм матчинга

### Факторы оценки совместимости
1. **Музыкальные предпочтения** (40%)
   - Общие исполнители и треки
   - Совпадение жанров
   - Сложность музыкального вкуса

2. **Психологическая совместимость** (35%)
   - Анализ эмоционального профиля
   - Темперамент и характер
   - Ценности и интересы

3. **Поведенческие факторы** (25%)
   - Активность в приложении
   - История свайпов
   - Отзывы о матчах

### Формула совместимости
```
MatchScore = (MusicSimilarity * 0.4) + (PsychologyCompatibility * 0.35) + (BehaviorScore * 0.25)
```
